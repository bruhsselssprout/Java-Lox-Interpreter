# Chapter 4 Challenges
## Challenge 4.4
`Add support to Lox’s scanner for C-style /* ... */ block comments. Make sure to handle newlines in them. Consider allowing them to nest. Is adding support for nesting more work than you expected? Why?`

### To test my challenge 4.4 solution, use the following Makefile commands:

To check through the REPL interactive terminal, simply run:
```sh
$ make run
```

To check through the included test file "block_comments.lox" (open the file to see what it tests exactly), simply run:
```sh
$ make test
```

Once finished, to clean up, you can simply run:
```sh
$ make clean
```
